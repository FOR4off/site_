## 🚀 Как запустить?

### Способ 1: Открыть в браузере (самый простой)

1. Скачайте файл `index.html`
2. Дважды кликните по нему
3. Сайт откроется в вашем браузере

### Способ 2: Через локальный сервер (рекомендуется)

Если у вас установлен Python:

```bash
# Перейдите в папку с файлами
cd путь/к/папке

# Запустите сервер
python -m http.server 8000

# Откройте в браузере
# http://localhost:8000
Или с помощью Node.js:

bash
npx serve

🌐 Работа оффлайн
Сайт использует Service Worker, который:

Кэширует все файлы при первом посещении

Показывает сохранённую версию если нет интернета

Автоматически обновляет кэш при появлении сети

Важно: Для работы Service Worker нужен HTTPS или localhost.

❓ Часто задаваемые вопросы
В: Как убрать прелоадер быстрее?
О: В коде найдите setTimeout(hidePreloader, 2500) и поменяйте 2500 на нужное время в миллисекундах.

В: Как поменять цветовую схему?
О: В секции <style> найдите :root и поменяйте цвета:

--accent-cyan: #00ffff; — основной акцентный цвет

--accent-purple: #9d00ff; — дополнительный цвет

--bg-primary: #0a0a0a; — цвет фона

В: Как добавить реальную отправку формы?
О: В коде найдите обработчик contactForm.addEventListener('submit'...) и замените симуляцию на реальный fetch-запрос к вашему API.

В: Почему не работает Service Worker?
О: Service Worker работает только на HTTPS или localhost. Откройте сайт через http://localhost.
